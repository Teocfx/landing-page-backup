Ares App Gestão

Objetivos

O objetivo do Projeto Ares é desenvolver uma plataforma web intuitiva para gestão de estoque de pequenos comerciantes. O sistema oferece controle de entrada e saída de produtos, alertas, logs detalhados e compatibilidade multiplataforma. O desenvolvimento segue práticas de qualidade de software, garantindo uma solução robusta com controles centralizados.

Tecnologias Utilizadas

Stack Tecnológico

Desenvolvido com HTML5, CSS3 e JavaScript no frontend, utilizando Tailwind CSS para estilização e design responsivo e intuitivo. Backend desenvolvido com Python e framework Django. Sistema de versionamento com Git e GitHub. Prototipação realizada no Figma. Testes automatizados implementados com Pytest para garantir qualidade e confiabilidade do código.
