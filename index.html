Nome e Objetivos

Ares App Gestão

Objetivos

O objetivo do Projeto Ares é desenvolver uma plataforma web intuitiva para gestão de estoque de pequenos comerciantes. O sistema oferece controle de entrada e saída de produtos, alertas, logs detalhados e compatibilidade multiplataforma. O desenvolvimento segue práticas de qualidade de software, garantindo uma solução robusta com controles centralizados.

Pitch

Principais Pontos

O Ares App Gestão oferece dashboard intuitivo para visualização de dados em tempo real, gestão financeira completa com controle de receitas e despesas, sistema de controle de estoque integrado, relatórios gerenciais detalhados e interface responsiva acessível de qualquer dispositivo.

Tecnologias Utilizadas

Stack Tecnológico

Desenvolvido HTML5, CSS3 javascript no frontend design responsivo,intuitivo. Python com e framework django no backend.
